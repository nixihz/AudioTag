媒体工具

  • FFmpeg 9.0.2：LGPL 2.1 许可证、构建许可说明、对应完整源码。未启用 GPL / nonfree 扩展。
  • LAME 4.0：LGPL 许可证、对应完整源码。作为独立动态库提供，已关闭可选的 mpg123 解码器。
  • 实际 FFmpeg 配置、构建脚本、动态库打包脚本。这些工具通过子进程使用，不链接进 SwiftUI 客户端。

构建需在 Apple Silicon Mac 上安装 Xcode Command Line Tools、make、pkg-config、nasm 与 Python。将两个源码包放入 .build/release-tools/，将脚本放入 script/，创建 Python 虚拟环境 .venv，然后执行：

bash script/build_release_tools.sh

脚本校验原始源码 SHA-256，输出 FFmpeg / FFprobe 与可替换的 LAME 动态库；源码没有额外补丁。可修改或重新构建这些 LGPL 工具以供调试，但修改应用包后原 Developer ID 签名将失效，需要按你的本机流程重新签名，不得冒用发行者身份。
