AudioTag 1.0.0（1）

首次提供带 Sparkle 更新器的 Mac 发行版。

  • 陶土红原生工作台，集中整理音频标签、普通歌词和 JPEG / PNG 封面。
  • 识别中英文歌曲信息；最多批量处理 32 个文件，只更新选中且非空的字段。
  • 支持 MP4 转 MP3、选择音轨、使用视频首帧作为封面，以及 128 / 192 / 256 / 320 kbps 码率。
  • 始终导出新副本，拒绝覆盖已有文件。转 MP3 会重新编码，不能提高原始音质。
  • 内置 Python 标签引擎与 FFmpeg，无需另外安装 Python 或 Homebrew。
  • 应用菜单新增「检查更新…」，设置中可管理自动检查。更新包使用独立的 Ed25519 密钥签名。

安装与兼容性

适用于 Apple Silicon Mac，要求 macOS 26.0 或更高版本。不支持 Intel Mac。

下载 ZIP 并解压，将 AudioTag.app 拖到「应用程序」。已有未配置更新器的开发版，需要手动安装此版本一次。

隐私与限制

歌曲信息、音频和封面在本机处理。Sparkle 检查与下载更新时会连接官网；不向官网上传媒体文件。软件不提供在线封面搜索、删除标签或同步歌词时间轴编辑。
